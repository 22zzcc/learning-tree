# 🌳 学树（LearnTree）· 交互式知识树学习助手

一个**本地优先**的 Web 应用：用 AI 把你想要的领域分解成足够细小的概念树，从你「已经会的」地方开始生长，边学习边点亮概念之间的「为什么」。

## 1.0 功能主线

- 🎯 **AI 摸底定目标**：3 轮对话 + 前置知识自评清单，摸清你已掌握什么
- 🌳 **垂直知识树**：目标在顶部向下分解，粒度自适应（每片叶子 5 分钟能懂）；**分支不设上限**
- 🔬 **继续分解**：任何节点觉得不够细，点一下 AI 就往下再拆一层，理论上无限深
- ⚙️ **原理 + 易错点**：每个节点带定义、通俗原理、例子、为什么重要、易错点
- 🔗 **边点亮机制**：学完一个概念，AI 枚举相似例子并讲清「为什么引出下一个概念」
- 🟢🟠🟡⚪ **四色状态**：已掌握 / 学习中 / 模糊 / 未学，随时可手动改
- 🧠 **动态知识档案**：「我会什么」页面随学习自动长大，不是一次定死的快照
- 📸 **图片导出**：一键导出 PNG / SVG（带图例，可打印 A4）
- 📚 **并行学习线**：多条学习线独立推进，互不干扰
- 🎓 **费曼学习法 3×30**（2.0）：选中任意节点开启「理解 30 分钟 → 复述 30 分钟 → 举例应用 30 分钟」学习会话——AI 点评你的复述、指出理解缺口、出应用场景题并评分，完成后按表现自动加成掌握度（+10~20）；会话可随时中断续学
- 📅 **弹性时长与挑战模式**（2.0）：首页「今日学习计划」输入今天可用分钟数——「最少」模式告诉你保底学什么（优先补模糊/学习中的薄弱环节），「极限」模式在同样时间内塞进最多的概念；费曼会话的每阶段时长也可弹性调整（5/10/15/30 分钟）
- 🏅 **娱乐激励正反馈闭环**（2.0）：首页激励横幅显示连续学习天数（今天学一点火焰就不灭）与 10 个成就徽章——掌握概念、点亮关联、完成费曼、极限挑战、连续打卡都会自动解锁成就并弹出庆祝提示；学习 → 成就 → 更想学
- 📓 **复述笔记本 + 每周复盘**（2.0）：「复盘」页收集你每一次费曼复述（含 AI 评分与缺口），按周汇总学习数据（掌握/点亮/费曼/计划/复述均分/连续天数），一键生成 AI 周复盘与下周行动建议
- 🔭 **高维认知解读**（2.0）：认知升级后，对任意节点点「生成高维解读」——AI 结合你现在已掌握的全部概念，用更高维度的视角重新解读这个旧概念（深层原理 + 知识暗线 + 下一次升级会看到什么）；每次认知成长后都可重新生成

## 快速开始

```bash
npm install
npm run dev        # 打开 http://localhost:5173
```

首次启动自动内置 3 条演示学习线（短除法 / 经济新闻 / 自由泳），可先体验再删。

## 接入 DeepSeek API（可选）

1. 到 [platform.deepseek.com](https://platform.deepseek.com) 注册并创建 API Key；
2. 打开应用「⚙️ 设置」页，粘贴 Key（仅保存在本机浏览器 IndexedDB，不上传）；
3. 选择模型与分解深度：
   - **deepseek-chat**：DeepSeek 官方普通模型，速度快；
   - **deepseek-reasoner**：DeepSeek 官方推理模型，知识分解更深入、原理讲得更透（慢）；
   - **deepseek-v4-flash / deepseek-v4-pro**：其他服务的模型名，需要把「接口地址」改成提供该模型的服务；
   - **深度模式**：5~8 层、40~150 节点、分支不设上限；**标准模式**：3~5 层、15~40 节点；
   - 模型不支持 JSON 模式时会自动降级重试，无需手动设置；
4. 新建学习线即可获得真实的 AI 摸底、个性化知识树、继续分解与「边点亮」生成。

不配置 Key 时自动进入**演示模式**（内置 4 层模板），所有功能仍可完整体验。

## 数据与隐私

全部数据（学习线、知识树、知识档案、设置）存在本机浏览器 IndexedDB 中。
「设置 → 导出全部数据」可备份为 JSON。

## 技术栈

React 18 + TypeScript + Vite · D3.js（树形可视化）· Dexie/IndexedDB（本地存储）· Zustand（状态）· DeepSeek API（OpenAI 兼容）
